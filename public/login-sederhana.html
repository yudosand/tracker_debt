Kembali ke dashboardBuka kode untuk disalin

Satu password, tetap terhubung.

Pemasangan hanya dilakukan oleh pemilik spreadsheet. Setelah itu, dua pengguna cukup memasukkan password dashboard. Centang Ingat perangkat ini selama 30 hari agar hard refresh, tab baru, dan membuka ulang browser tidak meminta login Google.

Gunakan spreadsheet lama yang sudah berisi pinjaman. Penghubung ini membaca tab Transaksi yang sama; tidak membuat file baru, memindahkan data, atau mengubah jadwal utang.

1. Pasang kode pada spreadsheet lama

  1. Buka spreadsheet Lunas Anda, pilih Ekstensi → Apps Script.
  2. Buka kode Apps Script Lunas, klik Salin kode. Tempel seluruh kode ke file Kode.gs / Code.gs pada proyek baru. Jika sudah ada script lain, gunakan file baru bernama Lunas dan pastikan tidak ada fungsi doGet yang bertabrakan.
  3. Simpan proyek. Beri nama Lunas — Login sederhana.

2. Atur password Anda

  1. Di Apps Script, buka Setelan Project / Project Settings (ikon roda gigi).
  2. Di Script Properties, tambahkan properti APP_PASSWORD. Isikan password khusus dashboard minimal 6 karakter (password panjang lebih sulit ditebak). Gunakan password yang berbeda dari password Google Anda.
  3. Kembali ke Editor, pilih fungsi setupLunas, lalu klik Jalankan. Pemilik memberikan izin Google pada tahap ini. Jika Google menampilkan peringatan aplikasi belum diverifikasi, periksa bahwa proyek tersebut milik Anda dan berisi kode yang baru dipasang sebelum melanjutkan.
  4. Setup menyimpan identitas spreadsheet dan hash password, menghapus properti password polos, serta mencabut sesi lama. Baris Transaksi tidak berubah.

3. Deploy sekali

  1. Klik Deploy → Deployment baru → Aplikasi web / Web app.
  2. Execute as / Jalankan sebagai: Saya (pemilik). Who has access / Siapa yang memiliki akses: Siapa saja / Anyone. Jika opsi ini tidak tersedia karena kebijakan organisasi, administrator perlu mengizinkannya.
  3. Klik Deploy dan salin URL Web app yang berakhir /exec. Penghubung menolak pembacaan dan pembayaran tanpa sesi password yang valid, walaupun URL-nya dapat dibuka publik.

4. Masuk ke dashboard

  1. Buka dashboard → Google Sheets, isi URL penghubung dan password.
  2. Centang Ingat perangkat ini, lalu klik Masuk.
  3. Pengguna kedua memakai URL penghubung dan password yang sama pada perangkatnya. Ia tidak perlu memberi izin OAuth Google untuk menggunakan dashboard. Akses langsung ke spreadsheet tetap mengikuti izin berbagi Google Sheets.

Jika opsi ingat perangkat tidak dicentang, sesi berlaku hingga 12 jam di tab tersebut. Sesi yang diingat berlaku maksimal 30 hari. Browser privat atau penghapusan data situs dapat menghapus sesi lebih awal. Tombol Keluar mencabut sesi perangkat; mengganti password melalui langkah 2 mencabut semua sesi.

Pemeliharaan

Untuk memperbarui kode: tempel versi terbaru, simpan, lalu Deploy → Kelola deployment → Edit → Versi baru → Deploy. URL /exec tetap sama. Tidak perlu menjalankan setup ulang kecuali ingin mengganti password atau spreadsheet.

GitHub hanya menyimpan kode dan halaman publik. Jangan menaruh password, token sesi, isi jurnal, atau ID spreadsheet pribadi di repository. Sesi dashboard disimpan di browser saat opsi ingat perangkat dipilih; password dan token OAuth Google tidak disimpan di browser.

Repository private tidak otomatis membuat GitHub Pages privat. Lihat ketentuan GitHub Pages. Penghubung menggunakan Apps Script yang dijalankan sebagai pemilik dan google.script.run.

Jika belum terhubung

Periksa URL /exec, deployment Execute as Me dengan akses Anyone, serta keberhasilan setup. Domain dashboard harus cocok dengan ALLOWED_ORIGIN di Script Properties, default https://yudosand.github.io tanpa path. Pengujian login nyata memerlukan deployment di akun pemilik; pengujian lokal hanya memverifikasi logika dan antarmuka.
