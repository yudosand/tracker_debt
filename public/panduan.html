Lunas · panduan pemasangan

Simpan cicilan Anda di Google Sheets.

Konfigurasi awal dilakukan sekali di Google Cloud. Setelah itu, dashboard dapat membuat spreadsheet dan mencatat pembayaran langsung dari browser—tanpa memasang Apps Script.

Yang perlu Anda siapkan: akun Google pribadi, akses ke Google Cloud Console, dan website Lunas di GitHub Pages. Client ID yang dibuat bersifat publik. Tidak perlu memberikan password, client secret, atau access token kepada siapa pun.

1. Buat proyek Google Cloud

  1. Buka Google Cloud Console → New project, lalu masuk menggunakan akun Google Anda.
  2. Isi nama, misalnya Lunas Debt Tracker, lalu buat proyek. Jika akun organisasi membatasi pembuatan proyek atau aplikasi, gunakan proyek yang diizinkan administrator.
  3. Pastikan proyek Lunas yang baru dibuat sedang dipilih pada pemilih proyek di bagian atas.

2. Aktifkan Google Sheets API

  1. Buka Google Sheets API pada proyek tersebut.
  2. Klik Enable / Aktifkan. Dashboard menggunakan API ini untuk membuat, membaca, dan menambah baris spreadsheet.

3. Siapkan layar izin Google OAuth

  1. Buka Google Auth Platform. Jika diminta, klik Get started.
  2. Di Branding / App information, isi nama Lunas Debt Tracker serta email dukungan dan kontak pengembang Anda.
  3. Untuk akun Gmail pribadi pilih audience External. Untuk penggunaan sendiri, biarkan aplikasi berstatus Testing.
  4. Di Audience → Test users, tambahkan email Google yang akan Anda gunakan di dashboard.
  5. Di Data Access → Add or remove scopes, tambahkan scope berikut (dapat dimasukkan manual jika belum muncul di daftar):
    https://www.googleapis.com/auth/drive.file
    Scope ini membatasi akses ke file yang dibuat/diberikan kepada aplikasi. Jangan memilih akses penuh ke seluruh Google Drive atau seluruh spreadsheet.
  6. Simpan konfigurasi. Jangan publikasikan aplikasi ke semua pengguna hanya untuk pemakaian pribadi. Jika Google menampilkan informasi izin, periksa proyek, akun, dan scope yang diminta sebelum menyetujuinya.

4. Buat OAuth Client ID

  1. Buka Clients → Create client.
  2. Application type: Web application. Nama: Lunas GitHub Pages.
  3. Di Authorized JavaScript origins, tambahkan persis:
    https://yudosand.github.io
    Jangan tambahkan /tracker_debt/ di origin. Field ini hanya berisi protokol dan domain.
  4. Authorized redirect URIs tidak diperlukan untuk alur token popup yang dipakai dashboard ini.
  5. Klik Create, lalu salin Client ID, bentuknya seperti 123456789-abc.apps.googleusercontent.com. Jangan menyalin atau membagikan Client secret.

Untuk pengembangan lokal saja, tambahkan origin http://localhost:5174 dan buka http://localhost:5174/tracker_debt/. Ini opsional; pemakaian website GitHub Pages hanya membutuhkan origin domain GitHub di atas.

5. Hubungkan dashboard dan buat spreadsheet

  1. Buka dashboard Lunas, lalu pilih menu Google Sheets.
  2. Tempel Client ID di kolom OAuth Client ID Google. Kosongkan URL / ID spreadsheet untuk pemasangan pertama.
  3. Klik Simpan konfigurasi, kemudian Hubungkan Google. Pilih akun yang tadi ditambahkan sebagai test user dan tinjau izin yang diminta.
  4. Setelah terhubung, klik Buat spreadsheet baru. Dashboard membuat file Lunas — Debt Tracker di Google Drive Anda, dengan tab Transaksi dan Panduan.
  5. Tautan Buka spreadsheet akan muncul. Status dashboard menjadi Google Sheets terhubung setelah pembacaan data berhasil.
  6. Buka Ringkasan, lalu Tambah utang. Data asli dimulai kosong. Data demo tidak diunggah otomatis.

6. Uji satu pembayaran

Untuk memeriksa koneksi, Anda bisa membuat kontrak yang diberi nama Uji koneksi dengan angka percobaan. Jangan memakai tombol pembayaran pada kontrak asli sebelum transfernya benar-benar selesai.

  1. Tambah kontrak uji, lalu buka Google Sheets: harus muncul baris dengan aksi add.
  2. Klik Tandai dibayar pada kontrak uji, lalu konfirmasi. Di spreadsheet muncul aksi pay; nominal dan tenor sisa di dashboard berkurang satu angsuran.
  3. Di Riwayat pembayaran, batalkan catatan terakhir jika diperlukan. Aksi undo ditambahkan; transfer bank tidak terpengaruh.
Kontrak dan transaksi uji tetap ada sebagai riwayat; belum ada fitur menghapus kontrak. Anda juga bisa langsung memakai data asli dan menguji pencatatan setelah pembayaran pertama benar-benar dilakukan.

Penggunaan sehari-hari

  • Setelah melakukan transfer manual, klik Tandai dibayar. Dashboard hanya mencatat; tidak mengirim uang.
  • Data diambil kembali setelah setiap pembayaran dan setiap 30 detik saat halaman aktif. Bisa juga lewat tombol muat ulang.
  • Access token hanya berada di memori tab, sehingga setelah reload atau sesi berakhir Anda perlu menekan Hubungkan Google lagi. Client ID dan pilihan spreadsheet tetap tersimpan di browser.
  • Untuk perangkat/browser lain, gunakan Client ID yang sama dan URL spreadsheet yang telah dibuat, lalu login akun Google yang sama. Jangan menekan Buat spreadsheet baru jika ingin menggunakan data yang sama.
  • Spreadsheet lama yang bukan dibuat oleh aplikasi ini belum didukung oleh pemilihan URL langsung. Buat file lewat dashboard agar izin drive.file tersedia.
  • Jangan mengurutkan atau menghapus baris jurnal, mengubah ID/aksi/versi, atau mengganti header. Gunakan filter view jika ingin meninjau data. Semua koreksi pembayaran dilakukan melalui dashboard.

Arti perhitungan

Pokok pinjaman Rp10 juta dan tenor 12 bulan dengan cicilan Rp1,1 juta menghasilkan total kewajiban Rp13,2 juta. Setelah 4 kali bayar, terbayar Rp4,4 juta dan sisa Rp8,8 juta / 8 bulan. Sisa ini termasuk bunga cicilan, bukan saldo pokok bank atau angka pelunasan dipercepat.

“Perlu dibayar bulan ini” mencakup angsuran sampai akhir bulan yang belum tercatat, termasuk tunggakan. Jatuh tempo tanggal 29–31 disesuaikan ke hari terakhir bulan pendek. Cicilan parsial, bunga berubah, denda, dan restrukturisasi belum dicakup.

MasalahYang perlu diperiksa
origin_mismatchTambahkan https://yudosand.github.io sebagai authorized JavaScript origin. Jangan memasukkan path repository.
access_denied / aplikasi TestingTambahkan email login sebagai test user di Audience. Periksa akun dan proyek yang dipilih.
Popup tidak munculIzinkan popup untuk website ini, pastikan koneksi ke Google tersedia, lalu klik Hubungkan Google lagi.
403 / akses ditolakPastikan Google Sheets API aktif. Gunakan spreadsheet yang dibuat melalui aplikasi ini, Client ID yang sama, akun yang sama, dan scope drive.file.
404 / file tidak ditemukanPeriksa URL spreadsheet, izin file, serta akun Google. Jangan masukkan URL Apps Script.
Respons penyimpanan terputusMuat ulang data dan lihat riwayat sebelum membuat transaksi baru. Pengiriman ulang ID yang sama tidak dihitung dua kali.

Jurnal tidak validPeriksa perubahan manual pada header, nomor, ID, dan urutan baris. Gunakan version history Google Sheets untuk memulihkan perubahan yang salah.

Client ID otomatis untuk website

Opsional: di GitHub → repository yudosand/tracker_debt → Settings → Secrets and variables → Actions → Variables, tambahkan GOOGLE_CLIENT_ID. Jalankan ulang workflow deployment. Client ID akan menjadi nilai awal formulir. Jangan menyimpan client secret atau token di variabel frontend.

Website GitHub Pages bersifat publik. Data Google Anda tetap privat dan tidak ditanamkan ke build atau repositori. Setiap pengguna harus memiliki izin Google sendiri untuk membaca file yang dipilih.
